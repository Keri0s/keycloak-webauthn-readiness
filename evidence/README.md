# Hồ sơ minh chứng mẫu

CH-01–CH-04 là cấu hình; VA-01–VA-04 là vá lỗi; XT-01–XT-04 là xác thực; NK-01–NK-04 là nhật ký.

Các file hiện là mẫu/fixture phục vụ rubric và CLI. Cần thay bằng bằng chứng đo từ lab, kèm nguồn, thời điểm và người đánh giá trước khi nghiệm thu. Không dùng trạng thái mẫu để tuyên bố lab đã đạt tiêu chí. Bằng chứng chạy tests nằm ở docs/validation/.
