# Tài liệu public

- [README gốc](../README.md): mục đích, cấu trúc, cách bắt đầu.
- [ROADMAP](ROADMAP.md): phần đã làm, phần cần làm tiếp, giới hạn kết luận.
- [Ma trận truy vết](truy_vet.csv): bảng đối chiếu đủ 20 mã FR-01…08, NFR-01…04, IF-01…04, DR-01…04.
- [Bằng chứng](validation/README.md): phân biệt readiness tests, kịch bản phiên và mutation audit.
- [Django lab](../apps/lab/README.md): vai trò từng module và điều kiện môi trường.

Tài liệu trao đổi giảng viên, SRS gốc và workflow nội bộ không nằm trong bản public. Một số metadata/lịch sử vẫn giữ đường dẫn tài liệu nội bộ để bảo toàn xuất xứ; đó không phải file bị thiếu trong quá trình build.
